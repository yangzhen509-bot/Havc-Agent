# Havc-Agent 操作指南

适用对象：联调人员、产品演示、研发试用。  
工程路径：`/Users/yz/Desktop/比赛/havc/Havc-Agent`

---

## 1. 环境准备

```bash
cd /Users/yz/Desktop/比赛/havc/Havc-Agent
conda activate havc-agent
pip install -r requirements.txt
cp .env.example .env   # 若尚无 .env
```

在 `.env` 中配置 OpenAI 兼容网关：

```bash
LLM_PROVIDER=alibaba
CUSTOM_LLM_API_KEY=你的密钥
CUSTOM_LLM_BASE_URL=http://你的网关/v1
CUSTOM_LLM_MODEL=你的模型名
LLM_TIMEOUT_SECONDS=30
```

未配置 Key 时自动走规则引擎，功能可演示，但 LLM 推理链会显示降级。

---

## 2. 启动控制台

```bash
conda activate havc-agent
python -m streamlit run havc_agent/app_web.py
```

浏览器打开提示的本地地址（默认 `http://localhost:8501`）。

---

## 3. 控制台分区说明

| 区域 | 作用 |
|------|------|
| 左侧「系统接入」 | 查看 Provider/Model、测试 LLM 连通 |
| 左侧「Agent 集群」 | 查看各 Agent 启停与优先级（来自 `config/agents.yaml`） |
| 左侧「场景参数」 | 调节内外温、湿度、日照、SOC、雨量、玻璃温度等 |
| 左侧「乘员」 | 配置在座人数与人体特征 |
| 左侧「闭环热仿真」 | 启动/停止/单步：舱温动力学 + Agent 每 10s 闭环更新 |
| **仅执行推理** | 单次多 Agent 推理（无热步进） |
| 顶栏 | 品牌区 + 关键工况标签 + 请求 ID（RID） |
| Tab「运行总览」 | 仿真曲线、多温区结果表、分区只读状态 |
| Tab「推理链路」 | 除雾链 + 各座位舒适链，可解释 |
| Tab「集群运维」 | Agent 注册表、RID、入站合并与回执 |

产品版不提供手调、语音指令与记忆学习页。

## 4. 推荐演示流程（5 分钟）

1. 侧栏保持默认「夏季暴晒」类参数（高温内温 + 强日照）。  
2. 点 **启动闭环热仿真**，观察舱温/PMV 曲线每 10s 变化，直至舒适收敛。  
3. 打开「推理链路」，说明：除雾 Agent（车厢级）与舒适 Agent（按座位）分工。  
4. 将 SOC 滑到 12%，再点 **仅执行推理** 或重启仿真，观察能耗 Agent 告警与风量封顶。  
5. 打开「集群运维」展示 RID 与 Agent 表。

### 闭环热仿真说明

1. 侧栏设好外温、内温（如 38℃）、日照与乘员。  
2. 点 **启动闭环热仿真**。  
3. 系统按 `C·dT/dt = Q_amb + Q_solar + Q_vent + Q_hvac` 每 10s 更新舱温，并重跑 Agent。  
4. 收敛条件：全体乘员 `|PMV|≤0.5` 且 `PPD≤10%`；也可「停止仿真」或「单步推进 10s」。

---

## 5. 启停 Agent

编辑 `config/agents.yaml`，例如关闭能耗：

```yaml
energy:
  enabled: false
```

保存后**重启** Streamlit 进程生效。产品版默认 `interaction` / `nlu` 为 `enabled: false`。

---

## 6. 测试与排障

```bash
conda activate havc-agent
PYTHONPATH=. pytest -q
```

| 现象 | 处理 |
|------|------|
| 显示离线 Mock | 检查 `.env` 变量名是否为 `CUSTOM_LLM_*`，并重启进程 |
| 连接测试失败 | 检查网关地址、网络、超时 `LLM_TIMEOUT_SECONDS` |
| 依赖缺失 | `pip install -r requirements.txt`（含 `pyyaml`） |

---

## 7. 安全提示

- API Key 仅放在 `.env`，勿提交仓库。  
- 演示环境车辆 ID 固定为 `havc-demo-001`，非实车下发。  
- 当前车辆总线为 Mock，真车 CAN/SOA 需在 `havc_agent/vehicle/adapter.py` 扩展。
