适用对象：联调人员、产品演示、研发试用。

---

## 1. 环境准备

```bash
cd /Users/yz/Desktop/比赛/havc/Havc-Agent
conda activate havc-agent
pip install -r requirements.txt
cp .env.example .env   # 若尚无 .env
```

在 `.env` 中配置 OpenAI 兼容网关（与 BrainCloud `cloud.llm` 同类）：

```bash
LLM_PROVIDER=alibaba
CUSTOM_LLM_API_KEY=你的密钥
CUSTOM_LLM_BASE_URL=http://你的网关/v1
CUSTOM_LLM_MODEL=你的模型名
LLM_TIMEOUT_SECONDS=30
```

未配置 Key 时自动走规则引擎，功能可演示，但 LLM 推理链会显示降级。

## 2. 启动控制台

```bash
conda activate havc-agent
python -m streamlit run havc_agent/app_web.py
# 或
bash scripts/run_web.sh
```

浏览器打开提示的本地地址（默认 `http://localhost:8501`）。

CLI 快速验算：

```bash
python -m havc_agent.app_cli list
python -m havc_agent.app_cli infer 0
```

## 3. 控制台分区说明

| 区域 | 作用 |
|------|------|
| 左侧「系统接入」 | 查看 Provider/Model、测试 LLM 连通 |
| 左侧「Agent 集群」 | 查看各 Agent 启停与优先级（来自 `config/agents.yaml`） |
| 左侧「场景参数」 | 调节内外温、湿度、日照、SOC、雨量、玻璃温度等 |
| 左侧「乘员」 | 配置在座人数与人体特征 |
| **执行推理** | 显式触发一次完整多 Agent 推理（推荐演示时使用） |
| 顶栏 | 品牌区 + 关键工况标签 + 请求 ID（RID） |
| Tab「运行总览」 | 多温区结果表、除雾/能耗告警、分区语音与手调 |
| Tab「推理链路」 | 除雾链 + 各座位舒适链，可解释 |
| Tab「学习记忆」 | 用户修正记录与清理 |
| Tab「集群运维」 | Agent 注册表、RID、入站合并与回执 |

## 4. 推荐演示流程（5 分钟）

1. 侧栏保持默认「夏季暴晒」类参数（高温内温 + 强日照）。  
2. 点击 **执行推理**，在「运行总览」查看主驾/后排温度与风量。  
3. 打开「推理链路」，说明：除雾 Agent（车厢级）与舒适 Agent（按座位）分工。  
4. 将 SOC 滑到 12%，再点 **执行推理**，观察能耗 Agent 告警与风量封顶。  
5. 在主驾输入「太冷了」回车，或手动调高温度 → 进入冷静期，记忆写入。  
6. 打开「学习记忆」查看修正链条；打开「集群运维」展示 RID 与 Agent 表。

## 5. 常用操作

### 5.1 自然语言控温

在分区卡片「自然语言指令」输入，例如：

- `太冷了` / `有点热`
- `调到 22 度`
- `风太大` / `吹脚`

回车后立即生效并写入记忆（交互快路径，不依赖完整重跑图）。

### 5.2 手动修正

调节「手动温度 / 风量 / 出风」任一控件 → 自动记忆，并进入冷静期（默认约 10 分钟内不自动覆盖用户设定）。

### 5.3 待确认（Pending）

低电量且推荐大风量时，可能出现「待确认」条：可 **确认下发** 或 **拒绝**（对齐 BrainCloud Pending Session）。

### 5.4 启停 Agent

编辑 `config/agents.yaml`，例如关闭能耗：

```yaml
energy:
  enabled: false
```

保存后**重启** Streamlit 进程生效。

## 6. 测试与排障

```bash
conda activate havc-agent
pytest -q
```

| 现象 | 处理 |
|------|------|
| 显示离线 Mock | 检查 `.env` 变量名是否为 `CUSTOM_LLM_*`，并重启进程 |
| 连接测试失败 | 检查网关地址、网络、超时 `LLM_TIMEOUT_SECONDS` |
| 改参数无反应 | 取消「自动推理」后点「执行推理」，或确认侧栏已改完 |
| 依赖缺失 | `pip install -r requirements.txt`（含 `pyyaml`） |
