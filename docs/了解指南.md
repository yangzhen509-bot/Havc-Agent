# Havc-Agent 了解指南

本文帮助快速理解系统「是什么、怎么决策、与 BrainCloud 的关系」。

---

## 1. 一句话定义

**Havc-Agent** 是面向新能源座舱的 **HVAC（空调热管理）多 Agent 系统**：  
根据环境 / 乘员 / 车辆状态，输出每座位温度、风量、出风模式，并在用户修正后持续学习偏好。

---

## 2. 为什么用多 Agent

单一大模型容易「拍脑袋调空调」。本系统拆成职责清晰的 Agent，再按优先级合成：

```text
决策优先级（高 → 低）

安全除霜（除雾 Agent / MAX）
  → 能耗软钳制（能耗 Agent）
    → 用户偏好逐步逼近（记忆）
      → 专业舒适锚点 PMV≈0（ISO 7730）
        → LLM 专业基准（可降级规则引擎）
```

| Agent | 粒度 | 做什么 |
|-------|------|--------|
| 交互快路径 | UI | 手调/语音修正直接落设定，不经 LLM 重推理 |
| 舒适 Agent | 每座位 | LangGraph：特征→记忆→PMV/RAG→LLM→逼近→安全 |
| 除雾 Agent | 车厢级 | 玻璃温度 / 露点 / 雨量 → 是否叠加除霜 |
| 能耗 Agent | 车厢级 | 低 SOC 限制风量、微调设定温度 |
| 语音理解 | 每座位 | 自然语言 → 设定增量 |

---

## 3. 与 Baic-BrainCloud 的对齐点

BrainCloud 是端云 Agent 集群（MQTT + 配置反射注册）。Havc 在 Python/LangGraph 侧吸收了同类企业能力：

| BrainCloud 概念 | Havc 落地 |
|-----------------|-----------|
| `cloud.agents.*.enabled` + priority | `config/agents.yaml` + `cluster/registry.py` |
| Pending Session | `cluster/pending.py` + 控制台确认条 |
| Ingest lease / 合并 | `cluster/ingest.py`（同场景短时去重） |
| Feedback 回执 | `cluster/feedback.py` + `InferenceResult.feedback` |
| request 可追踪 | `observability.new_request_id()`，顶栏 RID |
| Skill 文件约定 | `skills/` + 空调域参考（结构化字段、互斥） |
| OpenAI 兼容 LLM | `.env` 的 `CUSTOM_LLM_*`（对应 `cloud.llm`） |

Havc **不是** BrainCloud 的 Java 移植，而是同域（座舱空调）的可演示产品形态。

---

## 4. 一次推理在发生什么

1. **入站**：场景指纹进入 Ingest；过近的重复请求可合并（控制台显式「执行推理」可强制重算）。  
2. **除雾**：车厢级判定一次，缓存复用到各座位。  
3. **舒适**：每个在座乘员跑一条 LangGraph。  
4. **能耗**：在安全允许前提下软钳制。  
5. **落定**：防抖 + 冷静期 → 实际生效设定。  
6. **回执**：带 `request_id` 的 `ActionFeedback` 供运维页展示。

用户手动改温或说「太冷了」走 **交互快路径**：写记忆、锁冷静期，不必整图重跑。

---

## 5. 专业层：为什么不全靠 LLM

- **PMV/PPD（ISO 7730）** 为确定性计算，减少幻觉。  
- **知识 RAG** 注入季节/日照/人群/节能等原则，约束 LLM。  
- **规则引擎兜底**：无 Key 或超时仍可离线运行。  
- **除雾独立**：视线安全不与「舒服」混在一个 Prompt 里。

## 6. 产品边界（当前版本）

| 已具备 | 未接真车 |
|--------|----------|
| 多温区 PoC + 企业控制台 | CAN/SOA 实车信号（仅 Mock 总线） |
| 记忆学习与可解释链路 | 云端 Redis Pending 持久化 |
| 配置化 Agent 启停 | MQTT 上下行与 BrainCloud 直连 |
| Pending 确认雏形 | 量产 HMI/A2UI 卡片下发 |

## 8. 阅读路径建议

1. 读本文建立心智模型。  
2. 按《操作指南》跑通一次演示。  
3. 改 `config/agents.yaml` 体会集群启停。  
4. 深入 `engine.py` 与 `graph/nodes.py` 看合成顺序。  
5. 对照 BrainCloud `config.yaml` 的 `cloud.agents` / `cloud.llm` 理解配置同源思想。
